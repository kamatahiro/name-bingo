# 名前ビンゴ

同窓会・交流イベント向けのシンプルなビンゴアプリです。  
交流した人の名前をカードに入力して、名前が呼ばれたらマスをタップするだけで遊べます。

---

## できること

- 自分の名前を登録してゲームを始める
- 交流した9人の名前（＋趣味）をビンゴカードに入力する
- 名前が呼ばれたらマスをタップしてマーク
- 2マス揃ったら「リーチ！」バナーを表示
- 1列揃ったら「BINGO!」バナーを表示
- ビンゴ数をリアルタイムで画面に表示
- 最初からやり直す（リセット）

## 起動方法

インストール不要。ブラウザで開くだけで動きます。

### 方法1: ダブルクリックで開く（最も簡単）

`index.html` をダブルクリック → ブラウザで開く

### 方法2: VS Code の Live Server を使う（開発時推奨）

1. VS Code で `bingo` フォルダを開く
2. 右下の「Go Live」ボタンをクリック
3. ブラウザが自動で開く（ファイルを保存するたびに自動リロードされる）

> **Live Server のインストール方法**  
> VS Code の拡張機能タブで「Live Server」と検索してインストール

## テスト方法

自動テストは現在ありません。以下の手順で手動テストしてください。

### 基本動作の確認

1. `index.html` を開く
2. 名前入力欄に「テスト太郎」と入力し「カードを作る」をクリック
3. 9つのマスすべてに名前を入力し「ゲームを始める」をクリック
4. ビンゴカードが表示されることを確認

### リーチのテスト

1. 同じ行・列・斜めのマスを2つタップ
2. 緑の「リーチ！」バナーが表示されれば OK

### ビンゴのテスト

1. 同じ行・列・斜めのマスを3つすべてタップ
2. 金色の「BINGO!」バナーが表示されれば OK

### エラーのテスト

| 操作 | 期待する結果 |
|------|-------------|
| 名前未入力で「カードを作る」 | 赤いエラーメッセージが出る |
| 空欄がある状態で「ゲームを始める」 | 赤いエラーメッセージが出る |

## 実装済み機能

### 参加者用（index.html / app.js）

- **画面1: 名前登録** — プレイヤーの名前を入力してゲームを始める
- **画面2: カード入力** — 交流した9人の名前と趣味を入力する
- **画面3: ゲーム** — ビンゴカードをタップして遊ぶ

| 機能 | 説明 |
|------|------|
| ビンゴ判定 | 縦3・横3・斜め2 = 計8ラインを全チェック |
| リーチ判定 | 8ラインのうちいずれかが「2マーク・残り1」なら検出 |
| マーク切り替え | タップのたびに ON/OFF を切り替え |
| ビンゴ数表示 | 完成した列数をリアルタイムで更新 |
| カードシャッフル | ゲーム開始時にマスの並びをランダム化（Fisher-Yates）|
| リセット | 全状態を初期化して画面1へ戻る |
| XSS対策 | 入力値の HTML 特殊文字をエスケープして安全に表示 |

### 幹事用（host.html）

| 機能 | 説明 |
|------|------|
| 参加者名の一括入力 | 改行区切りのテキストエリアで全員分を入力 |
| シャッフル発表 | Fisher-Yates でランダム化し1人ずつ大きく表示 |
| カウンター表示 | 「第N人目 / 全M人」をリアルタイム表示 |
| 戻すボタン | 誤操作を1人分取り消せる |
| 番号付き発表済みリスト | 「1. 山田 太郎」形式でチップ表示 |
| 20人目 全画面メッセージ | 特別賞タイミングをトロフィーアニメーション付きで強調 |

## 次にやること（優先度順）

1. **リーチ中セルのハイライト**  
   リーチ状態の列にある「残り1マス」のセルに `.reach` クラスを付与して  
   黄色のボーダーや点滅で強調表示する。

2. **リーチ数の表示**  
   「ビンゴ: 0 列」の横に「リーチ: 1 列」を追加する。  
   `app.js` の `updateBingoCount()` 関数を修正するだけで実装できる。

3. **カードの保存（localStorage）**  
   入力内容をブラウザに保存して、ページを閉じても再開できるようにする。
